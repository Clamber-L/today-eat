# 今天吃什么 App UI 设计方案

版本：v0.1　日期：2026-10-06　配套文档：`docs/PRD.md`

## 1. 设计原则

- 打开就知道今天吃什么：首页第一屏是今天的早饭和晚饭，不需要额外点击
- 健康感可视化，但不说教：用颜色和小标签表达健康分、油盐糖，不弹窗提醒
- 一手可操作：常用操作（锁定、换一道、勾选购物）都在拇指可达区域，支持滑动手势
- 厨房场景友好：烹饪模式字大、屏幕常亮、按钮大，手上有油也能点

## 2. 视觉风格

关键词：清爽、食物感、轻量。

色彩（Material 3 主题，用 `ColorScheme.fromSeed` 生成）：

| 用途 | 颜色 | 说明 |
|---|---|---|
| 主色 seed | `#4CAF7A` 叶绿 | 健康、新鲜 |
| 强调色 | `#FF8A50` 暖橙 | 生成按钮、聚会餐标识 |
| 健康分 高（3～5） | 绿 `#43A047` | |
| 健康分 中（0～2） | 黄 `#F9A825` | |
| 健康分 低（< 0） | 橙红 `#E65100` | 不用纯红，避免焦虑感 |
| 背景 | `#FAFAF7` 米白 | 暗色模式跟随系统 |

字体：系统默认（iOS 苹方，Android 思源黑体）。标题 20/600，正文 15/400，辅助信息 13/400。

圆角：卡片 16，按钮 12，标签 999（胶囊）。

图片：菜谱封面统一 4:3，没有封面时用角色对应的插画占位（主食、荤、素、汤各一张）。

图标：Material Symbols Rounded。

- 点击菜品：进入菜谱详情
- 本周还没有清单时：显示空状态插画 +"生成本周菜单"大按钮

### 4.6 烹饪模式

> 以 `docs/RECIPE.md` 8.3 为准（用料核对 → 准备 → 开火前确认 → 一屏一步，计时结束后确认判断标准）。

│ ✕                 步骤 2 / 5 │
│                              │
│ [      步骤图片 / 视频片段   ]│

│                              │

- 屏幕常亮（wakelock）
- 计时器在后台继续，结束时本地通知 + 提示音
- 最后一步完成后："做完了，打卡这一餐？"（P1，扣减库存）

### 4.7 新建 / 编辑菜谱

入口：菜谱页"＋"打开底部弹层

```
┌─────────────────────────────┐
│ 添加菜谱                     │
│ ✨ 只写个名字                │  AI 生成完整草稿
│ 📋 粘贴 / 链接 / 截图导入     │  AI 解析
│ ✏️ 手动录入                  │
└─────────────────────────────┘
```

AI 方式提交后显示解析进度（异步任务），完成后进入确认页。确认页就是编辑器：顶部提示"AI 已填写 23 项，请检查"，AI 填写的字段带 ✨，可以按"只看 AI 填写的"逐项过一遍。

编辑器按阶段分页（详见 `docs/RECIPE.md` 9.1）：

1. 基础：封面、名称、角色、餐次、份数、难度、厨具、口感选项
2. 备菜：添加备料碗，选食材、填用量，用胶囊选择处理方式
3. 备调料：腌制 / 料汁 / 水淀粉，腌制选择作用的碗
4. 烹饪：选动作 → 自动带出火力、时长、判断标准 → 点选加入的碗或食材 → 修改主句；口感分支在步骤里展开填写
5. 检查：完整度、错误与警告列表，点击跳转到对应位置；健康分与油盐糖实时预览

只填了菜名和角色也可以保存；随时保存为草稿；任何阶段都可以点"✨ 帮我补全"。

### 4.10 设置

- 每周默认餐型：7 行 × 早 / 晚，和生成设置的样式一致
- 健康规则：每条规则一行开关；有参数的点进去调（如"一周高油高糖上限 2 道"用步进器）。规则文案写成人话，如"每顿晚饭至少有一道蔬菜"
- 忌口与过敏：食材搜索后添加，过敏项显示红色标记
- 账号：昵称、头像、退出登录

### 4.11 本周健康报告（从提示条或本周页面菜单进入）

- 荤素比例环形图
- 蛋白质来源分布（鱼虾、禽、红肉、蛋、豆制品）
- 高油高糖菜次数 / 上限
- 全谷物主食次数
- 晚餐人均油、盐用量 vs 推荐量（横向条形图）
- 底部：未满足的软规则 + "一键优化"（只对未锁定的菜重新生成）

## 6. Flutter 技术建议

| 方面 | 建议 |
|---|---|
| 状态管理 | Riverpod |
| 路由 | go_router，底部导航用 StatefulShellRoute 保留各 tab 状态 |
| 网络 | dio + retrofit（或手写），接口模型用 freezed + json_serializable |
| 本地缓存 | drift（SQLite）或 isar，缓存本周清单、购物清单、看过的菜谱 |
| 图片 | cached_network_image |
| 视频 | 外链用 url_launcher 跳转或 webview 内嵌；上传视频用 video_player（HLS） |
| 图片上传 | image_picker + 预签名 URL 直传 |
| 烹饪模式 | wakelock_plus、flutter_local_notifications |
| 图表 | fl_chart |
| 分享 | share_plus；图片卡片用 RepaintBoundary 截图 |

目录结构建议按功能划分：

```
lib/
  app/            路由、主题、全局 provider
  core/           网络、存储、通用组件、工具
  features/
    plan/         本周清单、生成、一餐详情、健康报告
    recipe/       列表、详情、编辑、烹饪模式
    inventory/    食材与库存
    shopping/     购物清单
    settings/     设置
    auth/         登录
```
