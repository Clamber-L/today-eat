# 菜谱内容规范

版本：v0.1　日期：2026-10-06　配套文档：`docs/PRD.md`、`docs/UI.md`

本文定义一道菜的内容结构、录入规范和详情页展示方式。官方内容、用户录入、AI 解析都使用同一套结构。

## 1. 目标

面向不会做饭的人：照着做就能做出来。每一步都要回答五个问题：

| 问题 | 对应字段 |
|---|---|
| 用多大火 | 火力 |
| 做什么 | 动作 + 一句话说明 |
| 放什么、放多少 | 加入（备料碗或食材 + 用量） |
| 做多久 | 时长 |
| 怎么算好了 | 判断标准 + 结果图 |

展示上不出现大段文字：图标、短句、卡片，细节默认折叠。

## 2. 整体结构

```
概览 → 用料 → 准备（备菜 + 备调料）→ 烹饪 → 装盘
```

| 阶段 | 内容 | 是否开火 |
|---|---|---|
| 概览 | 名称、份数、时长、难度、厨具、口感选择 | — |
| 用料 | 全部用料汇总，由系统自动生成，不单独录入 | — |
| 备菜 | 清洗、切配、泡发、解冻 | 否 |
| 备调料 | 腌制、调料汁、水淀粉、酱料 | 否 |
| 烹饪 | 按顺序的加热步骤，可分小阶段（焯水、炒制、收汁） | 是 |

规则：凡是用火的都算烹饪步骤，包括焯水、提前煮蛋；准备阶段只做不开火的事。

### 2.1 核心概念：备料碗

中餐炒菜节奏快，开火以后没时间切菜、调汁。所以开火前的所有切配、腌制、调汁都在准备阶段完成，每份成果放进一个带编号的"备料碗"：

```
A 肉丝（已腌制）   B 青椒丝   C 葱姜蒜   D 料汁
```

- 每个碗有字母编号、颜色、名称，用来区分的不只是颜色，色弱用户也能分辨
- 烹饪步骤里只写"倒入 A"，不重复列用料，界面上显示成彩色胶囊
- 腌制可以"在 A 碗中进行"：碗的编号不变，名称更新为"腌好的肉丝"
- 不是所有东西都要进碗：最后撒的盐、淋的香油可以在烹饪步骤里直接加食材

## 3. 用料

### 3.1 用量只填一次

每种食材只在它第一次出现的地方填写用量：

- 在备菜里切的，用量写在备菜项上（青椒 2 个，切丝）
- 在腌制、料汁里用的，写在对应项上（生抽 5ml）
- 在烹饪中直接加的，写在步骤的"加入"里（盐 1g）

同一种食材可以出现在多个地方（生抽：腌制 5ml + 料汁 10ml）。"用料"页由后端汇总生成，购物清单和油盐糖计算都基于这份汇总。

### 3.2 分组

汇总时按食材分类自动分组：主料、辅料（葱姜蒜、配菜）、调料。录入者不需要手动分组。

### 3.3 用量规范

- 一律用"数值 + 单位"。调料同时显示克数（或毫升数）和勺数，比如"盐 2g（约 1/3 茶匙）"，勺数由食材字典里的换算系数算出
- 单位说明：1 汤匙 = 15ml，1 茶匙 = 5ml。点击单位可以看到量勺示意图
- "适量"只允许用在点缀类用料上（葱花、芝麻）。油、盐、糖不允许写"适量"
- 需要"尝味再调"的情况，写参考值加说明："盐 1g，尝一下，不够再加"
- 份数可调：调整份数时，所有用量按比例缩放；时长不缩放，因为份数翻倍时烹饪时间不会翻倍。份数超过默认值 2 倍时提示"量大时可能需要分两次炒"

## 4. 准备阶段

### 4.1 备菜

| 字段 | 说明 | 示例 |
|---|---|---|
| 编号、名称 | 备料碗编号与名称 | B 青椒丝 |
| 用料 | 一种或多种食材，各带用量 | 青椒 2 个（约 150g） |
| 处理方式 | 枚举，见下表，可多选、有顺序 | 去籽 → 切丝 |
| 规格 | 尺寸描述 | 约 0.5cm 宽 |
| 说明 | 一句话，可选 | 竖着切，口感更脆 |
| 主动时长 | 需要人动手的时间 | 3 分钟 |
| 等待时长 | 泡发、解冻等不用看着的时间 | 泡发 2 小时 |
| 完成标准 | 判断标准，见 5.3 | 👀 木耳完全泡软，体积变大 3 倍 |
| 结果图 | 切好之后的样子 | |

处理方式枚举：洗净、去皮、去籽、去筋、切丝、切片、切块、切丁、切末、切段、滚刀块、拍碎、划花刀、泡发、解冻、沥干。每种切法在后台配有图示和尺寸说明，用户点击可以查看。

### 4.2 备调料

| 类型 | 说明 | 必填 |
|---|---|---|
| 腌制 | 作用于某个备料碗（在 A 碗中），加入调料，抓拌后静置 | 调料及用量、抓拌方法、静置时长、完成标准 |
| 调料汁 | 多种调料事先混合在新碗里 | 调料及用量、搅拌标准 |
| 水淀粉 | 淀粉 + 清水 | 比例 |
| 酱料 | 蘸料、拌料 | 调料及用量 |

腌制和泡发这类需要等待的项目标记为"可等待"。详情页和烹饪模式会建议先做这些，等的时候去做别的准备。

## 5. 烹饪步骤

### 5.1 字段

| 字段 | 说明 | 必填 |
|---|---|---|
| 小阶段 | 可选标题，用于长菜谱分段：焯水、煎制、炖煮、收汁 | 否 |
| 动作 | 枚举，见 5.2，决定图标和默认值 | 是 |
| 火力 | 关火、小火、中小火、中火、中大火、大火；烤箱、空气炸锅填温度 | 加热类动作必填 |
| 厨具 | 炒锅、蒸锅、砂锅、电饭煲、烤箱、空气炸锅 | 否，默认用菜谱的主厨具 |
| 加入 | 备料碗或食材，带份量（全部 / 一半 / 剩下的）和加入方式（倒入、沿锅边淋入、均匀撒入、分 3 次加入） | 否 |
| 主句 | 一句话说明，动词开头，建议 ≤ 20 字 | 是 |
| 补充说明 | 较长的解释，默认折叠 | 否 |
| 时长 | 区间，如 1～2 分钟；可勾选"以判断标准为准"，此时时长只作参考 | 是 |
| 判断标准 | 1～3 条，带感官类型 | 官方内容必填 |
| 口感分支 | 不同口感对应的时长和判断标准，见 5.4 | 否 |
| 结果图 | 这一步完成后的样子 | 关键步骤必填（官方） |
| 过程图 | 0～3 张 | 否 |
| 小贴士 | 做得更好的技巧 | 否 |
| 注意 | 安全和易错提醒：热油、蒸汽、刀具、容易糊锅 | 否 |
| 补救 | 出了问题怎么办，"问题 → 办法"的形式 | 否 |
| 视频片段 | 对应主视频的起止秒数 | 否 |

规则：一步只做一件事，也就是一个动作加上它要加入的东西。超过一个动作就拆成两步。

### 5.2 动作与默认值

动作由后台维护为"动作预设"。录入时选了动作，火力、时长、判断标准会自动填上默认值，录入者只需要修改。

| 动作 | 默认火力 | 默认时长 | 默认判断标准 |
|---|---|---|---|
| 热锅 | 中火 | 30 秒 | 👀 锅里的水分完全干了 |
| 倒油 / 热油 | 中火 | 30 秒 | 👀 油面出现细纹 |
| 爆香 | 小火 | 30 秒 | 👃 闻到明显香味，蒜片边缘微黄 |
| 滑炒 | 中大火 | 1 分钟 | 👀 肉全部变色，没有生的颜色 |
| 翻炒 | 大火 | 1 分钟 | 👀 食材颜色变亮，表面裹上油 |
| 煎 | 中小火 | 2 分钟 / 面 | 👀 底面金黄，可以轻松晃动 |
| 炸 | 中火 | 3 分钟 | 👀 表面金黄 👂 气泡声变小 |
| 焯水 | 大火 | 水开后 1 分钟 | 👀 颜色变亮 |
| 煮 | 大火转中火 | 5 分钟 | 👀 水大开，翻滚冒泡 |
| 蒸 | 大火 | 上汽后 10 分钟 | 🥢 筷子能轻松插透 |
| 炖 / 焖 | 小火 | 30 分钟 | 🥢 筷子能轻松插透 |
| 烤 | 200℃ | 15 分钟 | 👀 表面金黄 |
| 收汁 | 大火 | 2 分钟 | 👀 汤汁浓稠，能挂在食材上 |
| 勾芡 | 中火 | 30 秒 | 👀 汤汁变透明、变浓 |
| 调味 | 中火 | 20 秒 | 👅 尝一下咸淡 |
| 盛出 | 关火 | — | — |
| 静置 | 关火 | 5 分钟 | — |
| 装盘 | 关火 | — | — |

油温参考（作为术语表条目，见第 6 节）：

| 油温 | 约 | 判断 |
|---|---|---|
| 三四成热 | 90～120℃ | 油面平静，筷子插入有少量小气泡 |
| 五六成热 | 150～180℃ | 油面有细纹，筷子周围有密集小气泡 |
| 七八成热 | 210～240℃ | 油面冒青烟，筷子周围气泡很多、有响声 |

### 5.3 判断标准

不会做饭的人最缺的是"怎么知道好了"。每条判断标准带一个感官类型，界面上用固定图标显示：

| 感官 | 图标 | 示例 |
|---|---|---|
| 看 | 👀 | 肉丝全部变白，没有粉色 |
| 听 | 👂 | 滋滋声变小 |
| 闻 | 👃 | 闻到葱香 |
| 戳 / 摸 | 🥢 | 筷子能轻松插透土豆 |
| 尝 | 👅 | 尝一下，咸淡合适 |

写法要求：写具体、可观察的状态，避免"炒熟""炒香"这种笼统说法。

### 5.4 口感分支

同一道菜，不同的人想要的口感不同。菜谱可以定义口感选项，相关步骤为每个选项填写不同的时长和判断标准：

```
菜谱口感选项：脆（默认） / 软

步骤 6 翻炒青椒
  脆：30 秒   👀 青椒颜色变亮，表面油亮
  软：90 秒   👀 青椒变软，表皮微微起皱
```

- 一道菜可以有多个口感维度，比如土豆炖牛腩有"土豆：成块 / 软烂"和"牛肉：有嚼劲 / 软烂"
- 用户在详情页顶部选择一次，所有相关步骤的时长和判断标准同步切换，总时长也重新计算
- 选择按用户、按菜谱记住，下次打开默认是上次的选择

### 5.5 自动推导

后端根据结构化数据自动计算，不需要录入：

- 准备时长：主动时长之和，等待时长只取最长的一项（等的时候可以做别的）
- 烹饪时长：步骤时长之和，按当前选择的口感计算
- 用料汇总：见 3.1
- 油盐糖等级与健康分：基于用料汇总，规则见 PRD 6.4。炸、煎的菜分开记录"用油量"和"估算摄入量"，按动作预设里的吸油系数估算
- "下一步预告"：如果下一步要加入某个备料碗，当前步骤提示"下一步用 D 料汁，先搅一下放在手边"

## 6. 术语表

"爆香""勾芡""焯水""收汁""五成油温"这类词对新手是障碍。后台维护一份术语表：

| 字段 | 说明 |
|---|---|
| 术语、别名 | 勾芡 / 打芡 |
| 一句话解释 | 倒入水淀粉，让汤汁变浓稠 |
| 详细说明 | 可选 |
| 图片或短视频 | 可选 |

主句、说明和贴士里出现术语时自动识别，界面上加虚线下划线，点击后弹出解释。

## 7. 写作规范

适用于管理员、用户和 AI 生成的内容。

1. 一步一个动作，超过一个就拆开
2. 主句动词开头，建议 ≤ 20 字，比如"倒入肉丝，快速划散"
3. 火力、时长、用量都写在结构化字段里，不写进主句；展示时由界面拼出来
4. 数字一律用阿拉伯数字
5. 每一步至少一条判断标准；下肉、收汁、出锅这类关键步骤配结果图
6. 判断标准写可观察的状态，不写"炒熟""适度"
7. 安全相关的内容（热油、蒸汽、刀具）写进"注意"，不要混在贴士里
8. 常见失败写进"补救"，比如"粘锅了 → 下次腌制最后加一勺油"
9. 尽量少用术语；必须用的，确保术语表里有这个词

## 8. 详情页展示

### 8.1 原则（照顾阅读困难的用户）

1. 先图标，后文字：火力、动作、时长、感官都有固定图标，扫一眼就知道
2. 每张卡片结构和位置固定，读几步之后就形成习惯
3. 渐进展开：默认只显示主句、加入、火力、时长、判断标准和结果图；补充说明、贴士、注意、补救都折叠
4. 重点加粗：数字（用量、时长）和火力
5. 信号不只用颜色：备料碗用"字母 + 颜色"，火力用"图标格数 + 文字"
6. 字号跟随系统设置，另外提供"大字模式"；行距 1.6，左对齐
7. 每一步都可以语音朗读，烹饪模式下可以开自动朗读
8. 一屏只放一个阶段，不在同一屏混合用料、准备和步骤

### 8.3 烹饪模式

从详情页底部"开始做菜"进入，全屏、屏幕常亮，按阶段推进：

1. 用料核对：清单逐项勾选，"都齐了"再进入下一阶段
2. 准备：每个备料碗一张卡片，做完勾选。开始腌制、泡发这类可等待的项目时，顶部出现倒计时横条"A 腌制中 08:21"，同时提示"现在可以做 B 青椒丝"
3. 开火前确认："A、B、C、D 都准备好了吗？"列出所有碗
4. 烹饪：一屏一步

```
┌─────────────────────────────┐
```

### 8.4 时间线视图（P1）

详情页提供一个"时间线"切换，横向展示准备和烹饪的时间分布，让用户看清哪些步骤可以同时做、总共要多久。

## 9. 录入

### 9.1 App 编辑器

按阶段分页，用料汇总自动生成，不需要单独录入：

```
基础信息 → 备菜 → 备调料 → 烹饪 → 检查
```

- 备菜：添加备料碗 → 选食材、填用量 → 选处理方式（胶囊多选）→ 规格可选
- 备调料：选类型（腌制 / 料汁 / 水淀粉）→ 腌制选择作用的碗 → 添加调料
- 烹饪：选动作 → 自动带出默认的火力、时长、判断标准 → 点选要加入的碗或食材 → 修改主句
- 检查：显示完整度和问题列表，点击直接跳到对应位置

### 9.2 AI 导入

用户粘贴文字、链接或截图，或者只输入菜名，AI 按本规范生成草稿：拆出备料碗、拆分步骤、补全火力、时长和判断标准，并估算油盐糖。AI 填写的字段带 ✨ 标记，用户确认后才保存。详见 PRD 6.7。

### 9.3 校验规则

后端在保存时校验。错误会阻止发布；警告不阻止发布，但会降低完整度。

| 规则 | 官方内容 | 用户内容 |
|---|---|---|
| 步骤引用的备料碗必须已定义 | 错误 | 错误 |
| 每个备料碗至少被引用一次 | 错误 | 警告 |
| 加热类动作必须有火力 | 错误 | 警告 |
| 每步时长 > 0，或勾选"以判断标准为准" | 错误 | 警告 |
| 每步至少一条判断标准 | 错误 | 警告 |
| 关键步骤（下肉、收汁、出锅）有结果图 | 警告 | — |
| 油、盐、糖用量为数值 | 错误 | 警告 |
| 口感分支的 key 在菜谱口感选项中 | 错误 | 错误 |
| 主句超过 30 字 | 警告 | 警告 |

## 10. 数据模型

替换 PRD 中原有的 `RecipeIngredient`、`RecipeStep`。

```
Recipe            + equipment[], texture_dims[{key, label, options[{key, label}], default}],
                    prep_minutes(自动), cook_minutes(自动), completeness(自动)

PrepItem          id, recipe_id, phase(cut/season), kind(wash/cut/soak/thaw/marinate/sauce/slurry/dip/other),
                  label('A'), name, color, target_prep_item_id(腌制等就地操作),
                  instruction, active_seconds, wait_seconds,
                  cues[{sense, text}], result_media_id, tips[], sort_order, ai_fields[]
PrepItemInput     id, prep_item_id, ingredient_id, amount, unit, amount_text,
                  cut_styles[], cut_spec, note, sort_order

CookStep          id, recipe_id, sort_order, stage, action, heat, temperature_c, equipment,
                  title, detail, duration_min_s, duration_max_s, until_cue(bool),
                  cues[{sense, text}],
                  variants[{dim_key, option_key, duration_min_s, duration_max_s, cues[]}],
                  tips[], warnings[], rescues[{problem, fix}],
                  image_media_ids[], result_media_id, video_start, video_end, ai_fields[]
StepAddition      id, step_id, sort_order, prep_item_id?, ingredient_id?,
                  amount, unit, amount_text, portion(all/half/rest), method

RecipeIngredientSummary   recipe_id, ingredient_id, total_amount, unit, group   -- 后端汇总，只读

ActionPreset      key, name, icon, default_heat, default_duration_s, default_cues[],
                  oil_absorb_ratio, is_heating
CutStyle          key, name, description, image_media_id
Glossary          id, term, aliases[], short, detail, media_id
UserRecipePref    user_id, recipe_id, texture_choices{dim_key: option_key}, servings
```

`cues` 中 `sense` 取值：look / hear / smell / touch / taste。
`heat` 取值：off / low / medium_low / medium / medium_high / high。
